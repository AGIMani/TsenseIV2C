# 四指与拇指的独立指尖捏合约束

2026-09-28，将主项目原有拇指–食指约束扩展到全部四指。

| 手指 | MediaPipe 点对 |
| --- | --- |
| 食指 | 4–8 |
| 中指 | 4–12 |
| 无名指 | 4–16 |
| 小指 | 4–20 |

## 行为与参数

每对分别使用当前帧 `rho = ||P4 - Ptip|| / ||P5 - P17||` 计算意图。所有手指沿用食指参数：完整捏合比例 0.08、开始吸合比例 0.50、权重 65。`u = clip((0.50-rho)/(0.50-0.08), 0, 1)`，`alpha = u²(3-2u)`。

每对激活时加入 `sqrt(65*alpha) * (FK4-FKtip) / robot_palm_width` 的三维软约束。食指、中指、无名指、小指分别触发和释放；多对同时接近时共同参与优化。仅加入非零权重的残差，不对没有接近拇指的其他手指添加接触目标。掌宽与阈值仍取输入三维骨架，未增加历史吸附状态或输出滤波。

残差、解析雅可比、有限差分回退、候选初值比较、线搜索和损失统计使用同一组接触项。复用原 FK 和关节雅可比，保留原迭代预算、关节限位与后续碰撞/轨迹控制。软约束会与可达性及其他目标折中，不能保证任意输入下实体指尖精确接触。

## 接入位置

- `TsenseI_retargeting/toporetarget.py`：公共求解器，自动覆盖 V2、A3.0、A3.0 with ID、A3.2、A3.2 with ID 的左右手 profile 和网页/Qt 入口。
- `src/utils/retarget_runtime.py`：原“4–8捏合”控件改为“拇指与四指捏合”，统一开关、阈值和权重生效。
- `diagnostics.pinch.pairs`：以 `index / middle / ring / pinky` 分别提供点对、输入距离、比例和 alpha；生成完整分析数据时还包含各对求解后的距离。原 `diagnostics.pinch` 顶层的距离与 alpha 保留食指含义，兼容现有读取代码。
- `pinch_enabled=False`、权重 0、关闭拓扑优化时，所有接触项均停用；reset 或无效输入清除所有激活对。

独立 Wuji 演示项目不在本次修改范围内。现有 Python 服务/Qt 进程需要重启以加载更新；本次没有重启控制进程、连接真机或部署远端。

## 验证与边界

`tests/test_topo_pinch.py` 验证四指独立阈值与尺度/旋转/平移不变性、同时激活与单独释放、重置、无效输入、开关/零权重、NumPy/auto 解析雅可比中心差分及有限差分求解。5 个 profile × 左右手 × 4 种捏合共 40 种模型组合均验证关节限位、有限值和相较关闭约束的间距改善。

下表为左手的构造输入：以各模型初始骨架为基础，把输入拇指尖移至所选手指尖附近 1 mm，求解 30 帧后的间距。未包含相机、碰撞修正、轨迹或真机执行，不能作为真实手势精度保证。

| 模型 | 食指 | 中指 | 无名指 | 小指 |
| --- | ---: | ---: | ---: | ---: |
| V2 | 0.404 mm | 0.704 mm | 1.213 mm | 1.359 mm |
| A3.0 | 0.547 mm | 0.456 mm | 0.639 mm | 1.663 mm |
| A3.0 with ID | 1.327 mm | 0.882 mm | 1.038 mm | 1.910 mm |
| A3.2 | 1.386 mm | 1.324 mm | 1.333 mm | 2.098 mm |
| A3.2 with ID | 0.519 mm | 0.355 mm | 0.680 mm | 1.244 mm |

修改前代码保存在 `.work/pinch_four_fingers/before_toporetarget.py`，使用同一当前 profile 比较。关闭捏合、完全释放、只有食指激活三组各 24 帧扰动序列的输出逐值一致，最大关节差均为 0。

A3.2 with ID 左手、NumPy 后端，每种场景 4 轮、每轮 160 帧，交换前后版本求解顺序，热身后统计：

| 场景 | 修改前 P95 | 修改后 P95 | 变化 |
| --- | ---: | ---: | ---: |
| 张手、无接触项 | 16.944 ms | 16.937 ms | -0.05% |
| 仅食指触发 | 17.051 ms | 16.871 ms | -1.06% |
| 四对同时触发 | 15.048 ms | 15.394 ms | +2.30% |

本组离线求解耗时变化在此前 5% 预算内，但没有测量摄像头到真机的端到端延迟。完整数据见 [metrics](20260928_four_finger_pinch_metrics.json)，复核脚本在 `.work/pinch_four_fingers/verify.py`。

回归期间确认 `test_v3_2_latency.py` 在修改前代码上也因旧的零角度期望失败：当前模型下限是 0.005 rad（0.286°）。测试现改为生成限位内的伸指目标，并保持原 5°/0.1° 的误差要求，未修改运行时关节限位。

测试使用工作区内专用 `--basetemp` 避开系统临时目录权限问题；所有测试均使用模拟数据，没有发送真机命令。

最终 134 项测试通过，覆盖 `test_topo_pinch`、交互图稳定性、拇指几何、NumPy FK、伸指响应、A3.2 模型集成、网页会话和 A3.0 恢复连续性。
