# 自动轨迹恢复不再重置 retarget

## 修改

`online_control/online_motion_track/a30/session.py::A30WebSession.command` 区分 `browser_rebase` 的两种用途：

- **自动恢复**（`resume_from_commanded_pose=true`）：保留关键点滤波状态及原始观测时间、retarget 上一解和初始化解、交互图历史、当前手势目标、目标侧碰撞处理状态。
- **手动建立起始姿态**：保持原先行为，依据反馈/后备姿态建立目标侧状态并清空求解与滤波历史。

自动恢复仍调用 `A30Control.rebase`：验证反馈与最后成功下发姿态，从该姿态重建 Ruckig/直接模式采样状态、同步采样侧碰撞检查、清除旧发送数据并递增流 epoch。目标侧状态与实际下发轨迹分开管理，下一帧正常目标仍须经过原先的轨迹与碰撞检查。没有扩大碰撞/限位容差，也没有改变滤波参数。

实际手丢失及超过 300 ms 的观测间隔仍按原逻辑重置滤波；自动恢复不会更新或伪造观测时间戳。
