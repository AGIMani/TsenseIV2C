# 直接下发链路的低延迟滤波

适用 A3.0 / V2 网页的“关闭 Ruckig 限速”模式。启用该模式便自动使用滤波，无需另一个开关；保留实时下发、模式切换停发及手动重新开启流程。Ruckig 开启时不叠加此滤波。

## 算法及接入位置

`online_control/online_motion_track/direct_filter.py` 在控制线程按实际 dt 计算，不缓存识别帧、不预测未来目标。每关节分别采用自适应指数滤波：

```
error = target - last_checked_pose
tau = 0.004 + 0.012 / (1 + (error / 0.03)^2)  # 秒，error 单位 rad
alpha = 1 - exp(-dt / tau)
candidate = last_checked_pose + alpha * error
```

小误差接近 16 ms 时间常数，大误差接近 4 ms。更新是输入与上一输出的凸组合，不产生预测超调；不构成速度、加速度或 jerk 限制。候选输出仍须经过路径碰撞检查，然后转换行程/角度并编码下发。碰撞检查的实际接受姿态回写到滤波器，避免接触期间积累运动。重建起始姿态、模式切换、恢复下发时同步滤波状态。

A3.0 使用 500 Hz 采样；浏览器发送已检查并编码的结果，不在碰撞检查后再次滤波。V2 在其控制采样阶段使用相同滤波器。没有新增依赖，部署打包清单已包含新模块。

## 记录和查看

- `control_target`：滤波前目标，沿用每次 retarget 的记录。
- `direct_filter_detail`：状态轮询时捕获输入、滤波候选、碰撞后输出和滤波参数，A3.0 约 10 Hz。
- `direct_filter`：收到的碰撞后滤波样本；`sent=true` 仅在成功 USB 写入后记录，预览和离线回放均为 false。A3.0 记录实际接收到的流样本，并非承诺捕获服务器每一个 tick。
- `h7` / `conversion` / `downlink`：沿用原下发格式。直接模式不伪装为 Ruckig 曲线。
