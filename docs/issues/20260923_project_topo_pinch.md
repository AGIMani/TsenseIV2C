# 主项目 TopoRetarget 4–8 捏合接入

按用户截图设置：启用捏合，完整捏合比例 0.08，开始吸合比例 0.50，权重 65。

- `src/ui/form3_window.py`：阈值组合被拒绝时还原控件和数值，避免显示与实际配置不一致。
- 原有资产、标定、关节限位、各入口迭代预算、碰撞处理和 Ruckig 轨迹处理沿用现状。未增加平台的额外输出低通或冷启动20次迭代；实时项目仍使用自己的时序和迭代预算。

## 算法

`rho = ||input4-input8|| / ||input5-input17||`

`u = clip((0.50-rho)/(0.50-0.08), 0, 1)`，`alpha = u²(3-2u)`。

`residual = sqrt(65*alpha) * (FK4-FK8) / robot_palm_width`。

只添加4–8的接触目标；当前模型的拓扑耦合仍可能间接影响其他手指。开关关闭、权重为0、输入张开或关闭拓扑求解时接触项不生效。阈值作用于求解器收到的同帧骨架，未新增90 mm掌长预处理。
