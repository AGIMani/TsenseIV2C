## 生效内容

- 两款 A3.2 的跟踪和播放共用新版缩放机构公式；直线反馈采用同一曲线的数值逆。
  SDK 线性角限制为 0.005°–89.995°，应用仍用 0.005–1.565 rad。
- SDK 行程限位：DIP/小指 PIP 12.44 mm，其余 PIP 16.95 mm，MCP 19.63 mm，
  四指旋转 ±20°。应用保留更窄的侧摆 ±0.34 rad 及 MIT 99°/119° 标定限位。
- 食指/无名指 MCP 可使用完整应用范围，不再卡在旧几何解析解的 1.5229 rad。
- 静态链接 SDK 1.1.9 协议实现，原生共享库已重新构建；状态提供新版版本号和固件手别。
- 保留 POSIX USB/TCP、可选固件版本查询、无自动运动、软件停止不发失能、MIT 50:1、
  现有模型/拇指零位/通道方向。A3.0 与 V2 的控制算法未修改。
- 两种部署包包含重编译所需 SDK 源码。track/play 环境继续隔离，未添加 Qt。

同一旧动作角度现在按新版 SDK 产生行程；动作文件仍保存模型角度，不改写原文件。
已运行服务须在停止控制后分别重启 track/play，再重新建立页面会话，确保 Python
换算与原生库同时更新。本次没有连接、使能或驱动实物。

## 回归问题修复（2026-10-09）

- 模型 profile 默认使用网页已有的 NumPy 解析后端，不再依赖可选 Pinocchio；显式指定
  后端仍生效。5 款型号、左右手的 FK 和解析雅可比均与独立数值计算对照。
- 两项镜像测试错误地要求独立人工标定的左右手关键点完全对称。现改为测试临时生成的
  镜像关键点，并检查求解器加载各手自己的标定、原文件字节不变；URDF 镜像及 V2
  状态隔离检查保留，没有覆盖已保存的标定。
- 轨迹测试显式区分原参考限值与当前共享默认限值；两组均验证变步长速度、加速度、
  加加速度、相位比例和最终到达目标。保留原严格容差，没有调整生产运动限值。

  服务端正常处理浏览器取消连接，意外传输错误仍保留诊断；关节说明同步当前侧摆范围。
