# A3.2 with ID：2026-11-16 外壳模型

网页左右手使用 `TsenseI_hand_left_20261116.zip` 中的新左手 CAD；右手由左手在基坐标
`Y=0` 平面镜像生成。此次替换仅适用于 `TsenseI_v3_2_withid`，裸手模型保持独立。

## 关节范围

| 关节 | 模型与网页编辑范围 |
| --- | --- |
| 拇指根部第一转轴 | 0～130°（2.2689280275926285 rad） |
| 拇指根部第二转轴 | 0～100°（1.7453292519943295 rad） |
| 拇指 MCP / IP | 0～90°（π/2 rad） |
| 食指、中指、无名指、小指 MCP / PIP / DIP | 0～1.57 rad（约89.9544°） |
| 四指侧摆 | −20～+20°（±π/9 rad） |

所有关节初始角为0。新 CAD 的 origin、axis、装配零位和限位直接保留，不叠加旧版
拇指校正。资源同步脚本识别 `customer-exterior-20261116`，不会把精确角度改回旧值。

按用户补充要求，A3.2 with ID 的 SDK 数学域和项目下发限幅同步采用上述范围，
拇指根部不再受旧119°/99°配置截断，四指侧摆不再受旧±0.34 rad截断。
线性关节继续使用现有标定曲线，逐关节按新版 URDF 的端点计算命令和反馈。
裸手模型保留独立限位。所有验证使用离线设备或模拟设备，未运行实体手。

## 几何与配置

镜像同时处理关节平移和旋转、转轴方向、网格顶点与三角形绕序、质心与惯量。
左右手使用相同的标量关节角。右手属于几何镜像，来源记录保留此标记。

新版局部坐标系与旧模型不同，21点跟踪配置依据新关节中心和末端外壳重新生成，
右手关键点逐点镜像。自动生成的关键点保持待标定状态，不沿用旧模型的人工标定标签。
URDF 碰撞外包络、MJCF、初始姿态和关节分组同步更新，继续只启用不同手指之间的碰撞。

原始来源、名称映射和文件校验值见模型目录中的 `source_package` 与 `source_mapping.yaml`；
`source_20_outputs` 保存已适配项目名称的来源模型，供运动学核验使用。

重新导入命令（在项目根目录，参数为来源压缩包的实际位置）：

```bash
.venvs/track/bin/python tools/import_a32_customer_exterior.py /path/to/TsenseI_hand_left_20261116.zip
```

导入在临时目录中完成，校验和碰撞资源生成成功后替换模型；旧模型自动备份到项目
父目录的 `model-backups`。脚本不会执行来源包内的启动脚本或安装配置。

更新后分别重启 track/play 服务并刷新网页。两套 Python 环境继续独立，无 Qt 依赖。
