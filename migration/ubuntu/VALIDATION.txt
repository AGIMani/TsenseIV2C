hand 原生 Ubuntu 网页迁移验收记录
制作日期：2026-10-06
目标：Ubuntu 24.04 LTS / x86_64 / Python 3.12

结论与边界
网页动作后台已重写为无 Qt 的 Python 服务，迁移相关回归、真实浏览器离线流程和独立新环境安装检查通过。
原网页业务核心、输入、模型、标定与动作保留。原工程源码未改；所有改动仅在迁移副本。
软件检查在 Ubuntu 24.04 WSL Linux 用户态完成，未连接真实相机、USB机械手、Wuji手套或Quest头显。
因此不声称新电脑USB驱动、物理动作、500Hz硬实时或识别精度已通过现场验收。
此包保留原项目已存在的问题；全项目历史测试并非全部通过，具体见下文。

一、后台重构
- server.py：用序列化任务队列、控制权锁和Python事件循环替换Qt窗口/信号/定时器。
  保留原HTTP路由、控制权租约、同源检查、浏览器串口通道、模型切换和记录接口。
- v2_session.py：独立会话管理21关节、动作保存/覆盖/删除/导入导出、旧文件格式、
  左右手映射、序列/循环/单动作过渡、实时与同步控制、HEX显示及五指往返。
  保留500Hz Ruckig/DownlinkGuard、累计时间线、迟到跳帧、最终姿态收敛和写失败回退。
  换手取消旧任务并隔离旧帧；成功后按新手别重新seed并恢复控制偏好，失败则保持停止。
- v2_homing.py：非阻塞六轴一键找零、七步手动标定，保留遥测判定、时序、超时和取消。
- A30由服务循环调度会话，独立I/O线程保留；A32继续使用原独立控制线程与原生SDK。
- tracking包按需导入可选相机后端，避免网页网络输入被旧桌面cv2/torch依赖拖累。
- 移除Qt界面及GUI专属入口；保留网页复用的纯计算、协议、模型和标定工具。
- Linux原生启动入口重定位环境与数据路径；生成Linux依赖清单并排除Windows桥接/凭据。
- 补齐vendor/a3-cpp-sdk原CAD与许可证，建模工具改用包内默认路径。
  只改来源路径元数据，未更改模型几何、关节限位或标定数值。
