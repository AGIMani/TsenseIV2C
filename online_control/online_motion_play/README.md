# A3.2 with ID 网页动作控制

本页面仅支持 A3.2 with ID 的左手和右手。可在网页中调整关节、保存和导入导出动作，并通过运行服务的 Ubuntu 电脑使用原生 SDK 连接机械手。网页后台使用纯 Python，不依赖 Qt。

本页提供关节限位和 Ruckig 轨迹平滑，**没有接入碰撞检测或 Mink 避碰**。手势工作台的避碰设置不会应用到动作播放。

## 安装和启动

按项目根目录的 `README-UBUNTU.txt` 安装系统依赖，并保持 track、play 两套 Python 环境分开：

```sh
bash migration/ubuntu/install.sh play
bash migration/ubuntu/start-play.sh
```

在服务电脑上打开 <http://127.0.0.1:8765/>。首次运行不会自动连接或使能机械手。需要 USB 访问时按根目录安装说明设置 udev 和 dialout 权限；也可以使用 SDK 的 ETH 连接。

## 使用

1. 选择左右手；更换手别前先断开 SDK。模型始终为 A3.2 with ID。
2. 离线调整关节并保存动作。动作文件包含型号与手别，不接受其他型号或另一手别的动作文件。
3. 如需实机控制，在服务电脑的本机页面连接 USB 或 ETH SDK；按设备要求检查反馈和找零状态，然后手动开启实时关节控制或动作同步。
4. 点击停止、切换到后台或关闭页面会停止后续下发。停止不发送失能指令，设备可能继续执行已经接收的命令。

动作数据保存在 `runtime/ubuntu/play`，左右手使用各自文件。可通过页面导出备份；安装或升级时不要覆盖已有动作数据。

网页以 Ruckig 生成平滑的关节轨迹；机械手零位、方向、碰撞间隙与实际运动仍需现场验证。SDK 连接、找零、故障与反馈规则见 [A3.2 原生驱动](../../docs/A32_NATIVE_SDK.md) 和 [动作记录](../../docs/a32_motion_recording.md)。
